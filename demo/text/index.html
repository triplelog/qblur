Writing your own formula

A formula gives a colour for each pixel of the letters (or the border). It can use x y — where the pixel is, 0 to 1 across and down the text; px py — the same in pixels; t — time, so anything with t in it moves; c1 c2 — the two colours above it; pattern — the picture, or pattern(px * 2, py * 2) to read it elsewhere.

Colours are written (r, g, b) from 0 to 1. Some ideas: mix(c1, c2, y) · fromhsv((fract(x + t / 200), 0.8, 1)) · if fract(px / 20) < 0.5 then c1 else c2 · pattern * (1.2, 1, 0.8) · c1 * (0.6 + 0.4 sin(py / 4)). The full list is in the guide; the editor does whole pictures.
